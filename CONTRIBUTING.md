# Contributing

- Add one directory per Skill under `skills/`, containing `SKILL.md`.
- Use YAML frontmatter with a lowercase hyphenated `name` matching the directory and a concise `description`.
- Include purpose, when to use, required inputs, workflow, output format, quality checks, and safety boundaries.
- Map to Athenous MCP tools only after verifying exact live tool names and schemas.
- Never include credentials, customer data, or unsupported product claims.
- Test normal, incomplete-input, and unsupported-capability cases.
