# TikTok Ads Optimizer

## Purpose

Optimize TikTok paid campaigns through creative testing and funnel diagnosis.

## Use this Skill when

Use when evaluating paid media strategy or performance on the specified channel. Confirm campaign objective, conversion definition and reporting window first.

## Required context

- TikTok Ads data
- objective
- campaign/ad group/ad structure
- audience
- spend
- events
- creative
- placement
- landing page

If key data is absent, state what cannot be concluded and continue with a clearly labeled partial diagnosis. Never invent platform metrics or account structure.

## Specialized workflow

1. Validate event and attribution setup
2. inspect delivery, learning and audience scale
3. analyze hook/hold/watch metrics where available plus CTR, CVR, CPA and value
4. classify creative concepts and fatigue
5. align landing promise
6. design creator-style concept tests.

## Deliverables

- Creative performance matrix
- funnel diagnosis
- next concepts/scripts
- audience and budget recommendations
- caveats.

## Quality gates

- Keep campaign types, attribution windows, currencies and conversion definitions comparable.
- Separate platform-reported results from blended business outcomes and incrementality.
- Explain metric denominators and data coverage; don't infer causality from correlation.
- Prioritize changes by expected impact, confidence, risk and learning value.

5. Define success metrics and learning loop; do not promise reach or engagement outcomes.
