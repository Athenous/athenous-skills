# Athenous MCP integration

Athenous Skills work independently. MCP is an optional connection for compatible AI clients to access authorized Athenous capabilities.

The endpoint previously supplied for this project is `https://mcp.athenous.io/mcp`. Verify the current transport and secure authentication flow with Athenous documentation before configuring a client; do not assume all clients support the same transport or token mechanism. Discover tools and schemas at runtime. Never put tokens in Skills, source control, or shared prompts.
